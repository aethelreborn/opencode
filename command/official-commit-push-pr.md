# Commit, Push, and Open a PR

1. Run `git status`, `git diff HEAD`, and `git branch --show-current`.
2. If on the default branch, create a new branch with a descriptive name.
3. Stage the intended files explicitly, create one commit with a conventional message, and push the branch to origin.
4. Create a pull request with `gh pr create`, including a summary and a test plan.
5. Report the PR URL.
